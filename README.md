# 王者荣耀对局数据分析（AI 协作 · 数据科学方向）

> 一个"与 AI 协作完成"的游戏数据分析项目：从零构造 4,200 场模拟对局数据，
> 用 Python 完成全流程数据处理与可视化，输出一份自包含的数据分析报告。

## 项目亮点

- **零第三方图表库**：不依赖 matplotlib/seaborn，自研 SVG 渲染器（折线/柱状/散点/热力图），
  展示扎实的底层实现能力。
- **完整数据管线**：数据模拟 → 清洗加工 → 特征构造（KDA / GPM / Gold Share）→ 多维分析 → 可视化 → 报告。
- **可复现**：固定随机种子（seed=42），一条命令重跑全流程。
- **分析价值**：经济效率与胜负的关系（S 曲线）、KDA 边际效应、分路/英雄平衡、因子相关性等
  6 条可落地结论，贴近游戏数值策划真实分析场景。

## 快速运行

环境：Python 3.10+，仅需 `numpy` 与 `pandas`。

```bash
pip install numpy pandas

# 一键跑通全流程（种子固定，结果可复现）
python -m src.generate_data   # 生成原始数据
python -m src.analysis        # 清洗分析 + 出图
python -m src.build_report    # 生成 HTML 报告

# 打开报告
start reports/report_hok_analysis.html
```

## 数据怎么来的（诚实说明）

王者荣耀官方不提供开放对局数据集。本项目基于公开的游戏机制认知
（分路模板、经济成长、胜负结构等）用 `numpy` 构造**足够真实的模拟样本**，
重点展示的是**数据处理与分析的完整方法**；结论的价值在方法而非数据来源。
面试中被问到"数据是否真实"时，如实说明这是模拟数据即可——这正是数据科学
方法论中的常见课题（data synthesis / 生成数据的建模验证）。

## 核心发现摘要

| 维度 | 结论 |
|---|---|
| 经济 | GPM 从最低档到最高档，胜率从 45.0% 抬升到 55.7%；团队经济差 → 胜率呈典型 S 曲线 |
| KDA | 最高档（5.9）胜率 75.1%，最低档 26.6%；高位区间边际收益递减 |
| 死亡 | 与胜负相关性最强（r=-0.32），是最大负向因子 |
| 分路 | 镜像阵容设计下位置胜率收敛于 50%，位置无天然强弱，差异来自英雄与个人表现 |
| 时长 | 平均 17.6 分钟，峰值在 16–18 分钟；时长拉长场均击杀单调上升（滚雪球机制） |
| 英雄 | 登场率与胜率二维分析，识别版本热门与强度英雄 |

## 常见问题

- **为什么自研 SVG 图表？** 环境受限无 matplotlib，主动选择自研渲染器——
  反而成为简历上展示编码能力（坐标轴/刻度/布局的底层实现）的加分项。
- **数据真实性**：见上文"数据怎么来的"。模拟数据是数据科学的常见练习，
  面试时展示你能主动说明数据来源与局限，是加分行为。
