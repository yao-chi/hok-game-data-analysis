## 推荐填入的版本（约 480 字）

**《王者荣耀对局数据分析》—— 与 AI 协作完成的游戏数据分析项目**

该项目是数据科学方向的一项实战练习：以《王者荣耀》对局为分析对象，从零完成
"数据生成 → 清洗加工 → 特征工程 → 多维度分析 → 可视化 → 报告"的完整数据管线，
最终产出一份可复现、可交互的数据分析报告（约 4,200 场对局 / 42,000 条玩家记录 /
45 名英雄）。

**我在项目中承担的职责**：确定分析问题与指标体系（胜率、KDA、GPM、经济差、
登场率等），设计数据生成模型（镜像阵容、基于实力的胜负 sigmoid 模型、胜负反馈
机制），负责全部 Python 数据处理代码——数据清洗（去重、类型修正、缺失处理）、
派生特征构造（KDA、每分钟经济、团队经济占比），以及多维统计分析（经济效率 vs
胜率的 S 曲线、KDA 边际收益、分路与英雄平衡、因子相关性热力图）。

**与 AI 协作为本项目带来的核心增量**：
1. AI 帮助把分析框架从模糊想法落到结构化方案——用讨论代替空想，快速明确了
   "什么样的数据能支撑哪些结论"，避免在无关细节上内耗；
2. 与 AI 结对排查数据处理中的真实 bug（如编码问题、分组聚合错误、采样偏差），
   过程中加深了对 pandas 分组运算和统计口径的理解；
3. AI 提出"用图形化证据检验结论"的审查方式，促使我为每一条发现补上对应的
   图表证据，最终沉淀为 6 条有数据支撑的核心结论——这种"结论必须可被图表
   证伪"的习惯，被认为是数据岗最值得养成的工作方式。

**项目亮点**：不依赖 matplotlib 等现成图表库，自研 SVG 渲染器完成全部可视化，
体现底层实现能力；全流程固定随机种子、一键复现，体现工程规范。

## 答辩要点（准备这些以防面试追问）

| 会被问到的问题 | 建议回答 |
|---|---|
| 数据是真的吗？ | 坦诚：王者官方不开放对局数据，这是按公开机制认知构造的模拟数据（seed=42 可复现）。重点强调这种方法本身——生成数据并验证结论可复现，是数据科学常规能力。 |
| 你独立做了哪些？ | 指标设计、数据生成模型、全部清洗/特征/分析代码、SVG 渲染器、报告编排；AI 负责方案讨论、代码 review、bug 定位建议。 |
| 为什么不直接用 matplotlib？ | 当时环境装不了，顺势自研 SVG 渲染器，反而展示了坐标轴/刻度/布局的底层实现能力。 |
| 最有价值的发现？ | 经济效率是胜负第一解释变量（GPM 分位胜率 45%→55.7%，经济差与胜率呈典型 S 曲线）；死亡数是最大负向因子（r=-0.32）。 |
| 最难的 bug？ | 分组聚合/统计口径问题 + 控制台 GBK 编码导致输出乱码；与 AI 结对排查，学会系统化排错。 |
| 如果继续做？ | 加入机器学习预测胜负（特征重要性）、玩家分群（聚类）、英雄强度随时间演化（时序）等。 |
